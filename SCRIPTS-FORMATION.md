# Scripts de voix off — Vidéos de formation Billeterie Express

Mode d'emploi : chaque vidéo ci-dessous est autonome. Pour Google AI Studio, copiez le bloc « Voix off » d'une vidéo (et la ligne « Écran » pour le cadrage). Langue : français. Ton : professionnel, clair, phrases courtes. Les libellés entre guillemets sont exactement ceux affichés à l'écran — les dire tels quels.

**Séries : 1 vidéo client + 14 organisateur + 3 agent + 2 point de vente = 20 vidéos.**

# Série 1 — CLIENT (processus complet de réservation)

## Vidéo C1 — Réserver un billet : le processus complet
**Durée estimée** : 4 à 5 min
**Écran** : accueil → page événement → réservation → paiement → confirmation → billets

**Voix off** :

« Bienvenue sur Billeterie Express, la billetterie en ligne du Sénégal. Dans cette vidéo, nous suivons ensemble le parcours complet d'un client, de l'accueil jusqu'à son billet.

Tout commence sur la page d'accueil. Ici, les événements sont classés par catégorie : Concerts, Festivals, Spectacles, Conférences et Soirées. La section « Événements en vedette » affiche les prochains grands rendez-vous, avec pour chacun sa date, son lieu et le prix « À partir de » suivi du montant en FCFA.

Le client clique sur l'événement qui l'intéresse. Sur la page de l'événement, il retrouve la photo, la date, l'heure, le lieu, et la description complète. Dans la colonne de droite, le panneau « Choisir vos billets » liste les types de billets disponibles : Standard, VIP, Tribune… Pour chaque type, le client règle la quantité avec les boutons moins et plus. Les disponibilités sont indiquées en clair : « Stock illimité », « X ticket(s) disponible(s) en ligne », ou « Rupture de stock ». Il clique ensuite sur « Choisir mes billets ».

Étape suivante : la réservation. L'indicateur affiche les trois étapes — Panier, Paiement, Confirmation. Dans « Récapitulatif des billets », le client ajuste ses quantités ou ajoute un autre type avec « Choisir un type de billet… » puis « Ajouter ». Le total s'actualise en direct. Il remplit alors le formulaire « Informations de l'acheteur » : Nom complet, Email, Téléphone, Ville, et en option Adresse. Important : aucun compte n'est obligatoire pour réserver. Le client clique sur « Réserver ».

Vient le paiement. Sur la page « Réglez votre commande », il choisit son moyen de paiement — Wave ou Orange Money — puis saisit son numéro de téléphone. Ce numéro recevra la demande de confirmation de paiement. Il clique sur « Payer », suivi du montant en FCFA, et valide sur la page sécurisée DexPay.

Après confirmation, la page affiche « Paiement confirmé ! ». Les billets sont immédiatement générés : chaque billet possède un QR code et un code unique, valable une seule fois. Le message est simple : « Présentez le QR code de chaque billet à l'entrée. Un billet n'est valable qu'une seule fois. »

Les billets sont aussi envoyés automatiquement sur WhatsApp : le client reçoit son billet en image, avec un bouton « Voir mon billet ». Il peut également les télécharger depuis « Voir tous mes billets », les enregistrer en image ou les imprimer.

Enfin, si le client a créé un compte, il retrouve toutes ses réservations dans « Mes réservations », avec le statut — Payée, En attente de paiement… — et ses billets à tout moment. Et après l'événement, il pourra laisser son avis directement sur la page de l'événement.

C'est tout pour le parcours de réservation. Simple, rapide, et sécurisé. »

## Vidéo A2 — Scanner et valider un billet
**Durée estimée** : 2 min 30
**Écran** : /agent/scanner — Scanner un billet

**Voix off** :

« Voici le scanner. Le sous-titre est simple : « Présentez le QR code du billet à la caméra. » Le bouton « Liste des billets » vous ramène à l'espace agent.

Placez le QR code du billet dans le cadre de visée. La caméra vérifie automatiquement : un bip aigu signale une entrée acceptée, un son grave signale un refus. Pendant la vérification, un panneau affiche « Vérification… » puis le résultat en grand : « Entrée autorisée » sur fond vert, ou « Ticket invalide » sur fond rouge, avec le message correspondant.

Si la caméra ne fonctionne pas — permission refusée ou caméra indisponible —, un bandeau vous invite à autoriser l'accès ou à utiliser la saisie manuelle. Le bouton « Réactiver la caméra » relance le flux.

La saisie manuelle se trouve sous le scanner : « Saisir le code manuellement ». Saisissez le code du billet, par exemple BXT-4K7M-9P2X, puis cliquez sur « Valider ». Le format exact est indiqué sous le champ : « Format du billet : BXT-XXXX-XXXX. Le billet ne peut être utilisé qu'une seule fois. »

Après chaque tentative, la caméra se met en pause puis reprend automatiquement : vous pouvez enchaîner les entrées sans risque de double scan. Chaque tentative, acceptée ou refusée, est enregistrée dans l'historique de l'organisateur, avec votre nom d'agent.

Voyons maintenant les différents résultats que vous pouvez rencontrer. »

## Vidéo A3 — Comprendre les résultats de validation
**Durée estimée** : 2 min
**Écran** : /agent/resultat/{validation} — écran de résultat

**Voix off** :

« Après chaque scan, un écran de résultat s'affiche. Regardons les cas possibles.

Le meilleur cas : « Entrée autorisée », avec le message « Entrée autorisée - Bienvenue ! ». La fiche verte confirme le billet : Code, Titulaire, Type de billet, Événement, et Statut « Valide ». Laissez passer le spectateur.

Ensuite, le cas le plus fréquent au contrôle : « Ticket invalide ». Plusieurs motifs existent, et le message l'indique. « Ce ticket a déjà été utilisé. » : le billet a déjà donné entrée, la fiche affiche « Utilisé le » avec la date, l'heure et le nom de l'agent qui l'a validé. « Ticket introuvable - code inconnu. » : le code n'existe pas. « Ce ticket a été remboursé ou annulé. » : le billet n'est plus valable. Et « Ce ticket ne correspond pas à l'événement contrôlé. » : le spectateur présente un billet d'un autre événement.

Dans tous ces cas, refusez l'entrée et, si nécessaire, demandez au spectateur de contacter l'organisateur.

Après le contrôle, utilisez les boutons « Scanner un autre billet » pour enchaîner, ou « Liste des billets » pour revenir à la liste. Et retenez la règle absolue : chaque billet n'est valable qu'une seule fois, et aucun billet ne peut être scanné deux fois avec succès. »

## Vidéo P1 — Comprendre son tableau de bord et son stock
**Durée estimée** : 2 min
**Écran** : /point-de-vente

**Voix off** :

« Bienvenue dans l'espace point de vente. Ce tableau de bord sert à déclarer vos ventes de tickets physiques. Le sous-titre le résume : « Déclarez vos ventes de tickets physiques. Chaque vente génère immédiatement les billets QR de l'acheteur. »

Quatre statistiques résument votre activité. « Stock restant » : les billets qu'il vous reste à vendre, avec la mention « sur X attribué(s) ». « Tickets vendus » : le total déjà écoulé. « Chiffre d'affaires » : votre recette en FCFA. Et « Ventes déclarées » : le nombre d'opérations.

À gauche, la carte « Mon stock » liste votre attribution, événement par événement : le type de billet, son prix, et le restant en surbrillance — orange tant qu'il reste des billets, rouge à zéro. Si le carte affiche « Aucun stock attribué », c'est que votre organisateur ne vous a pas encore donné de tickets : contactez-le, le formulaire de vente restera indisponible.

En bas, le tableau « Mes ventes récentes » retrace votre historique : Date, Événement et Type, Acheteur avec son téléphone, Quantité, Total, et une Note facultative.

Vous êtes prêt à vendre. Voyons comment déclarer une vente. »

## Vidéo P2 — Déclarer une vente
**Durée estimée** : 2 min 30
**Écran** : /point-de-vente — formulaire « Déclarer une vente »

**Voix off** :

« Pour vendre, remplissez le formulaire « Déclarer une vente », sur la droite. Rappel important affiché en haut : « Le paiement est encaissé en espèces par le point de vente. » Vous encaissez donc l'argent en main propre ; le système génère seulement les billets.

Cinq champs. « Type de ticket » : la liste affiche l'événement, le type, et le nombre de billets restants ; les types épuisés sont grisés. « Quantité vendue » : un par défaut. « Nom de l'acheteur » : c'est le nom du porteur du billet, obligatoire. « Téléphone » et « E-mail » : optionnels, mais utiles pour retrouver le client. Vérifiez le stock, puis cliquez sur « Enregistrer la vente et générer les billets ».

La confirmation s'affiche en vert : « Vente enregistrée », avec la référence de la réservation — par exemple BEX-260323-ABC123 — et la consigne : « Remettez les billets QR à l'acheteur. » Un billet QR unique est généré automatiquement pour chaque unité vendue, au nom de l'acheteur, avec son code BXT unique.

Si le stock est insuffisant, le message vous prévient : « Stock insuffisant : il reste X ticket(s). » — corrigez la quantité et recommencez.

Votre vente apparaît immédiatement dans « Mes ventes récentes », et votre chiffre d'affaires se met à jour. Votre organisateur, lui, retrouvera cette vente dans ses Réservations, avec le canal « Physique » et le mode de paiement « Guichet ».

C'est tout pour le point de vente : stock, vente, billets. »
